# Nettoyage technique du 19 novembre 2026

Premier lot approuvé par l’utilisateur après l’inventaire. Les modules métier et
les données ne sont pas dans ce périmètre. Aucune migration de base n’est ajoutée.

## Référence d’archivage

Avant tout retrait, la branche `archive/pre-cleanup-20261119` a été créée sur
`8f5ea1ffd50f898f79724a81470103365f0ac92d`. Elle conserve les fichiers originaux,
y compris les anciens scripts opérateur et les copies métier du dossier backup/.
Le manifeste CLEANUP-20261119.json indique chaque chemin et son empreinte SHA-256.

Pour retrouver un fichier sans exécuter son code :

```bash
git fetch origin archive/pre-cleanup-20261119
git show origin/archive/pre-cleanup-20261119:chemin/du/fichier
```

La restauration dans l’arbre actif doit rester volontaire et revue. Ne pas
exécuter directement les anciens scripts de création/suppression de clients.

Retrait de sept dépendances runtime sans import détecté et d’un paquet de types :
@radix-ui/react-icons, @radix-ui/react-toast, @tanstack/react-table, cmdk, leaflet,
react-leaflet, react-globe.gl et @types/leaflet. Nettoyage correspondant de
optimizePackageImports. Le lockfile est mis à jour sans montée de version des
paquets conservés. npm signale 63 paquets installés supprimés, transitifs compris.

utilisée par Axios. MapLibre, le Kanban, les animations et les bibliothèques
utilisées par les écrans actifs sont conservés.

Ces chiffres décrivent les sources et dépendances retirées, pas un gain de temps
de chargement ni une taille de bundle mesurée.

## Éléments conservés

Les redirections /cockpit, /dashboard, /artist, /artists, /spotify-search, /quotes
et /invoices restent en place. Les outils historiques liés à des données et les
API V1/V2 ne sont pas retirés. Les connexions bancaires et prédictions commerciales
suspendues restent désactivées avec leur code. Discovery et les analyses
artistiques, événements, production, CRM/facturation, MCP, sécurité, documents
légaux, migrations, CI et configurations de développement/production sont gardés.
Les sauvegardes du VPS et les volumes Docker ne sont pas concernés.

## Déploiement

Ce lot modifie le frontend et les outils du dépôt ; le backend applicatif et son
schéma ne changent pas. Mettre à jour la branche puis reconstruire et recréer
uniquement le frontend avec les fichiers Compose du VPS. Si le déploiement avatar
précédent n’est pas terminé, sa migration 059 reste nécessaire indépendamment de
ce nettoyage. Ne pas utiliser git clean, supprimer de volumes ni purger PostgreSQL.
